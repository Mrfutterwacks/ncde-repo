# NCDE Repo Maintenance — How to Keep the Repo Current

## What happened (2026-09-27)

The GitHub repo (`Mrflutterwacks/ncde-repo`) had drifted behind the live system.
Changes made directly to the live machine were never folded back into the
canonical project tree, so `pacman -Syu` on other machines delivered stale
packages missing:

- `ncde-session.README.md`
- 10 sentinel Python files (`__init__.py`, `drivers.py`, `hwmon.py`, etc.)
- 17 `/etc/` config files (X11, D-Bus, pam.d, sysctl.d, etc.)
- 3 systemd unit files
- Packaging files in the wrong location

## How to prevent this

### The rule

**An NCDE change is unfinished until it is folded into the project and
delivered through a newer package in the GitHub repository.**

### The procedure (after every live change)

1. **Copy changed files from live into the project tree:**
   ```bash
   # UI files
   cp /usr/share/ncde/<file> my-project/files/full-patch-20260711/src/usr/share/ncde/<file>
   
   # Sentinel files
   cp /usr/local/bin/sentinel/<file> my-project/files/full-patch-20260711/src/usr/local/bin/sentinel/<file>
   
   # Config files
   cp /etc/<path>/ncde-<file> my-project/files/full-patch-20260711/src/etc/<path>/ncde-<file>
   
   # Systemd units
   cp /usr/lib/systemd/<scope>/ncde-<file> my-project/files/full-patch-20260711/src/usr/lib/systemd/<scope>/ncde-<file>
   ```

2. **Rebuild the embedded archive in the full-patch script:**
   ```bash
   cd my-project/files
   find full-patch-20260711 ncde-live-patch-20260711.sh vesper-patch-20260711 \
     \( -type d -name '__pycache__' -prune \) -o \
     \( -type f \( -name '*.pyc' -o -name '*prebak*' -o -name '*.reverted-*' \) -prune \) -o \
     -type f -print0 > /tmp/ncde-payload-files
   tar --null -T /tmp/ncde-payload-files -czf /tmp/ncde-payload.tar.gz
   base64 /tmp/ncde-payload.tar.gz > /tmp/ncde-payload.b64
   
   # Replace everything after the marker line
   SCRIPT="ncde-full-patch-20260711.sh"
   MARKER_LINE=$(grep -an '^__NCDE_PATCH_ARCHIVE_BELOW__$' "$SCRIPT" | head -1 | cut -d: -f1)
   head -n "$MARKER_LINE" "$SCRIPT" > /tmp/ncde-patch-new.sh
   cat /tmp/ncde-payload.b64 >> /tmp/ncde-patch-new.sh
   cp /tmp/ncde-patch-new.sh "$SCRIPT"
   chmod +x "$SCRIPT"
   cp "$SCRIPT" NCDE-Installer/ncde-full-patch-20260711.sh
   ```

3. **Run the preflight check:**
   ```bash
   cd my-project/files/NCDE-Installer/packaging
   bash publish.sh --check
   ```
   This verifies:
   - All live files match the staged tree
   - The embedded archive is complete
   - No unapproved paths
   - LaPivot palette transforms are correct

4. **Publish:**
   ```bash
   bash publish.sh
   ```
   This builds, signs, and uploads to GitHub.

### Quick audit command

To check if the repo is in sync with the live system:

```bash
# Check UI files
diff <(cd /usr/share/ncde && find . -type f ! -name '*.prebak*' ! -path '*__pycache__*' | sort) \
     <(cd my-project/files/full-patch-20260711/src/usr/share/ncde && find . -type f ! -name '*.prebak*' ! -path '*__pycache__*' | sort)

# Check sentinel files
diff <(cd /usr/local/bin/sentinel && find . -type f ! -name '*.prebak*' ! -path '*__pycache__*' | sort) \
     <(cd my-project/files/full-patch-20260711/src/usr/local/bin/sentinel && find . -type f ! -name '*.prebak*' ! -path '*__pycache__*' | sort)

# Check /etc/ files
find /etc -name '*ncde*' -type f ! -name '*.prebak*' | while read f; do
  rel="${f#/etc/}"
  [ -f "my-project/files/full-patch-20260711/src/etc/$rel" ] || echo "MISSING: etc/$rel"
done
```

If any of these output anything, the repo is out of sync.

## What is NOT in the repo (intentionally excluded)

- `usr/local/bin/LaPivot` — palette-patched at build time, not shipped as-is
- `usr/lib/systemd/system/ncde-apply.service` — generated by the package
- `usr/lib/systemd/user/ncde-update-check.service` — generated by the package
- `usr/lib/systemd/user/ncde-update-check.timer` — generated by the package
- `etc/geoclue/conf.d/90-ncde-static.conf` — machine-specific
- `home/stephen/.config/ncde-terminal/config.json` — user-specific
- Backup files (`*.prebak*`, `*.reverted-*`)
- Python cache (`__pycache__`, `*.pyc`)
