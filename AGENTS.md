# AGENTS.md — NCDE Project Instructions

**Read this file first before doing any work in this project.**

## Critical rule: the repo must never go stale

The GitHub Arch repository (`Mrflutterwacks/ncde-repo`) exists so that
`sudo pacman -Syu` makes every NCDE machine behave and look like the
operator's live NCDE system. **An NCDE change is unfinished until it is
folded into the project and delivered through a newer package.**

If you make any change to the live system — QML, JS, Python, C++, config,
systemd units, hooks, sentinel files, packaging — you MUST also:

1. Copy the changed file(s) into the canonical project tree under `files/`
2. Rebuild the embedded archive in `files/ncde-full-patch-20260711.sh`
3. Run `files/NCDE-Installer/packaging/publish.sh --check` to verify
4. Run `files/NCDE-Installer/packaging/publish.sh` to ship

See **REPO-MAINTENANCE.md** for the full procedure and audit commands.

## What is intentionally excluded from the repo

- `usr/local/bin/LaPivot` — palette-patched at build time
- `usr/lib/systemd/system/ncde-apply.service` — generated by the package
- `usr/lib/systemd/user/ncde-update-check.service` — generated by the package
- `usr/lib/systemd/user/ncde-update-check.timer` — generated by the package
- `etc/geoclue/conf.d/90-ncde-static.conf` — machine-specific
- `home/stephen/.config/ncde-terminal/config.json` — user-specific
- Backup files (`*.prebak*`, `*.reverted-*`)
- Python cache (`__pycache__`, `*.pyc`)

## Quick audit (run after any live change)

```bash
cd /run/media/stephen/NCDE-BACKUP/my-project/files

# Check UI files
comm -23 \
  <(cd /usr/share/ncde && find . -type f ! -name '*.prebak*' ! -path '*__pycache__*' | sort) \
  <(cd full-patch-20260711/src/usr/share/ncde && find . -type f ! -name '*.prebak*' ! -path '*__pycache__*' | sort)

# Check sentinel files
comm -23 \
  <(cd /usr/local/bin/sentinel && find . -type f ! -name '*.prebak*' ! -path '*__pycache__*' | sort) \
  <(cd full-patch-20260711/src/usr/local/bin/sentinel && find . -type f ! -name '*.prebak*' ! -path '*__pycache__*' | sort)

# Check /etc/ files
find /etc -name '*ncde*' -type f ! -name '*.prebak*' | while read f; do
  rel="${f#/etc/}"
  [ -f "full-patch-20260711/src/etc/$rel" ] || echo "MISSING: etc/$rel"
done
```

If any command outputs anything, the repo is out of sync — fix it before
finishing the task.
