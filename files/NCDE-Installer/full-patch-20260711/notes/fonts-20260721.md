# Fonts — Filigree tab refinement + typography wiring + app sync (2026-07-21)

Operator directive: the Filigree Fonts tab is the GLOBAL font control for the
entire shell; must be complete, professional, refined, commercial-grade,
consistent sizing, nothing janky.

## Audit findings (all verified against live + the ncde-wm decompile)
1. FAKE CONTROLS: Weight + Italic saved but applied NOWHERE (old
   Settings::applyFontSettings builds QFont(family,-1,-1,false); zero QML
   consumers of theme.fontWeight/fontItalic). Leading: theme.lineHeight existed
   (fallback 1.2) with ZERO consumers. Spacing: 5 consumer files out of ~40.
2. APP PROPAGATION BROKEN: shell (LaPivot) reads/writes sectioned
   ~/.config/ncde/fonts.json; ALL house apps (Hummingbird, Magpie, Abacus,
   Verve, NCDE Command) read + QFileSystemWatcher-watch the ncde-wm-era
   font.json — untouched since 2026-06-21. Fonts tab changes never reached them.
3. UI jank: NCDE default serif (Cormorant Garamond) absent from choices; no
   typography reset; label column widths mixed (50/78/100); previews ignored
   Spacing/Leading (sliders gave zero visible feedback); terminal font override
   hidden in Glass tab with its refresh hook wired to the Fonts tab (stale cfg).

## Fixes (operator chose "wire them for real"; specimen chips + terminal move
## were the recommended presentation options)
- notes/sweep-fonts.py: 104 sites / 24 files gain font.weight/font.italic/
  font.letterSpacing (sites owning bold/weight/italic keep theirs); lineHeight
  only on wrapped body text (5 sites). Neutral values render identically.
- ThemeTokens.lineHeight fallback normalised 1.2 -> 1.0 (was consumer-less).
  NOTE: first cut INSERTED a duplicate lineHeight property — hard QML compile
  error, caught by the ThemeTokens create-gate before staging. apply-fonts.py
  now replaces the existing line instead.
- notes/apply-fonts.py (16 anchored edits): Aa specimens (own face, uniform
  26px chips), Cormorant Garamond serif chip, custom-font not-installed hint
  (Qt.fontFamilies, cached once), Reset Typography pill, 72px two-line MEASURE
  sample with live spacing/leading, letterSpacing on TEXT RENDERING previews,
  terminal Font row moved Glass->Fonts (tint stays; BOTH tabs refresh cfg on
  visibility), 78px label column.
- ncde-fontsync: /usr/local/bin/ncde-fontsync + systemd user path unit mirrors
  fonts.json -> font.json atomically; apps' watchers pick it up live. Enabled
  for $USER_NAME + /etc/skel wants for new users.
- One-shot deploy migration (marker ~/.config/ncde/.fonts-wired-20260721):
  fonts.json dead keys normalised (fontWeight 400, fontItalic false,
  lineHeight 1.0) so wiring cannot change the shell's current look at relog.
  letterSpacing intentionally KEPT (was half-live in 5 files).
