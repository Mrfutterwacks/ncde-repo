Iris Chroma — every palette its own paint

All 90 presets, current vs proposed. Each proposed palette was rebuilt from its name (web-researched anchors, named HTML colors, colormagic.app matches), then spread so no two palettes sit within a ΔE of 13 of each other — the live set has 22 pairs close enough to read as the same color. Text inks are untouched: every theme keeps its exact readability. The little card mimics how the Iris Chroma card ramp will actually render.
